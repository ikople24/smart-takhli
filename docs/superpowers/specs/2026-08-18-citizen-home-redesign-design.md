# ดีไซน์เฟส 1: โครง citizen + หน้าแรกโฉมใหม่ (`/preview`)

วันที่: 2026-08-18 · สถานะ: อนุมัติแล้ว · อ้างอิงดีไซน์ภาพ: `docs/ดีไซน์ใหม่ Smart Takhli/` (branch `feat/app-redesign-canvas`)

## บริบท

รีดีไซน์ฝั่งประชาชนทั้งแอปตามแคนวาส "Smart Takhli Redesign" (9 จอ แนวทาง A — ทางการ
มินิมอล ม่วง `#7C3AED` ฟอนต์ Anuphan) งานใหญ่เกิน 1 รอบ จึงแบ่งเฟส:

1. **โครง citizen + หน้าแรก ← เฟสนี้**
2. Flow แจ้งเรื่อง 4 ขั้น (แทน `ComplaintFormModal`)
3. ติดตามสถานะ + รายละเอียด (แทน `/status`)
4. ข่าว & กิจกรรม (แทน `/activities`)
5. โปรไฟล์ (ต้องมีระบบระบุตัวตนประชาชนก่อน — ยังไม่ออกแบบ)

การ์ด Nav ล่างในดีไซน์ถูกลดเหลือ 3 แท็บ + ปุ่มแจ้งเรื่องกลางแล้ว (ตัดแท็บกิจกรรม —
จอข่าวเป็นหน้ารองเข้าจากหน้าแรก)

## การตัดสินใจหลัก (ตอบโดยเจ้าของโปรเจกต์)

- **เริ่มจากโครง + หน้าแรก** — ทุกเฟสถัดไปต่อยอดจาก shell เดียวกัน
- **ปล่อยผ่าน route คู่ขนาน `/preview`** — ไม่มีลิงก์เข้าจากที่ไหน merge เข้า main
  ได้โดยคนทั่วไปไม่เห็น; การสลับเป็นหน้าแรกจริงเป็นการตัดสินใจแยกทีหลัง นอกขอบเขตเฟสนี้
- **การทดสอบหลักทำบน local** (`npm run dev`) ตลอดเฟส — `/preview` เป็นกันชนตอน
  จะขึ้น production เท่านั้น ไม่ใช่ช่องทางเทสหลัก
- **จอกว้าง = app shell กึ่งกลาง** เนื้อหากว้างสุด ~480px พื้นหลังโทนอ่อน ไม่ทำ
  responsive หลายคอลัมน์ (เกินดีไซน์ที่อนุมัติ)
- **ฟีเจอร์หน้าแรกเดิมเก็บครบ** แปลงเข้าภาษาดีไซน์ใหม่ ไม่มีฟีเจอร์หาย
- **แนวทาง A: เปลือกใหม่ ข้อมูลเดิม** — UI ใหม่ทั้งชุด แต่ stores/API/logic ดึงข้อมูล
  ใช้ของเดิมทั้งหมด ไม่แก้ API แม้แต่เส้นเดียว ไม่แตะหน้าแอดมิน

## โครงไฟล์ (ตาม convention รายโมดูล — โมดูล `citizen`)

```
components/citizen/
  CitizenShell.tsx      — app shell: กว้างสุด ~480px กึ่งกลาง, ฟอนต์ Anuphan,
                          พื้นหลัง #F6F5FA, ครอบ BottomNav + FAB
  BottomNav.tsx         — เฟสนี้ 2 แท็บ + ปุ่มกลาง: หน้าแรก · [แจ้งเรื่อง] · สถานะ
  home/
    HeaderCard.tsx      — แถบ gradient ม่วง โลโก้ + ชื่อเทศบาลเมืองตาคลี
    EnvCards.tsx        — การ์ดคู่ PM2.5 + น้ำประปา (ค่า + ป้ายระดับสี)
    ComplaintCTA.tsx    — แบนเนอร์ "เริ่มแจ้งเรื่อง"
    ServiceGrid.tsx     — grid การ์ดบริการ (ดูรายการด้านล่าง)
    NewsSection.tsx     — หัวข้อ "ข่าวกิจกรรม" + การ์ดข่าว 3 รายการ + "ดูทั้งหมด ›"
lib/citizen/            — logic ล้วนที่เกิดใหม่ + เทสต์ __tests__/ (vitest)
pages/preview.tsx       — ประกอบหน้าแรกใหม่
```

- ฟอนต์ Anuphan โหลดด้วย `next/font/google` (subset `thai`+`latin`) ใช้เฉพาะใน
  CitizenShell — ไม่กระทบหน้าแอดมิน/หน้าเดิม
- โทเคนดีไซน์ (ม่วง `#7C3AED`→`#9050F0`, พื้น `#F6F5FA`, รัศมี 20–22px, เงานุ่ม)
  เป็น CSS variables ใน scope ของ shell — ไม่แก้ DaisyUI theme กลาง
- `/preview` เป็นหน้า public: ไม่ลง `ALL_PAGES`/permissions (เฉพาะ `/admin/*`)
  และ `middleware.js` ไม่ครอบ route นี้อยู่แล้ว

## การเดินข้อมูล (ของเดิมทั้งหมด)

| ส่วน | แหล่งข้อมูลเดิม |
|---|---|
| PM2.5 | endpoint เดิมที่อ่าน Mongo cache (`Pm25Latest`) — ห้ามเรียก DustBoy ตรง |
| น้ำประปา | API smart-papar เดิม (ตัวเดียวกับ `WaterQualityCard`) |
| หมวดแจ้งเรื่อง | `useMenuStore` |
| ข่าวกิจกรรม | fetch/store เดิมของ `ActivityFeed` (โมดูล activities) |

คอมโพเนนต์ใหม่เป็นเปลือกแสดงผลรับข้อมูลจาก hooks เดิม · ระหว่างโหลดแสดง skeleton
· ถ้า API ล้มให้ซ่อน/fallback ตามพฤติกรรมเดิมของหน้าแรกปัจจุบัน

## ServiceGrid — ฟีเจอร์เดิมเก็บครบ

การ์ดทางเข้าสไตล์ grid หมวดในแคนวาส: ตารางรถขยะ (`/garbage`) · ยืม-คืนอุปกรณ์
(sm-health) · แบบสำรวจการศึกษา (smart-school modal) · เช็คอินผู้สูงอายุ
(`/elderly/checkin`) — รายการสุดท้ายยืนยันตอนทำแผน โดยไล่จากการ์ด/โมดัลที่
`pages/index.tsx` เรียกอยู่จริง · แถบสถิติเว็บ (SiteStatsBar) + ปุ่มติดตั้งแอป (PWA)
ย้ายไปท้ายหน้าแบบเรียบ ๆ + Footer เดิม

## จุดที่ตัดสินใจแทนดีไซน์ (อนุมัติแล้ว)

- **แท็บโปรไฟล์ยังไม่แสดง** — ยังไม่มีระบบล็อกอินประชาชน Nav เป็น 2 แท็บ + ปุ่มกลาง
  จนกว่าเฟสโปรไฟล์จะมาถึง
- **กระดิ่งแจ้งเตือนมุมขวาบนยังไม่ใส่** — เหตุผลเดียวกัน
- **ปุ่มแจ้งเรื่องกลาง (FAB)** เปิด `ComplaintFormModal` เดิมไปก่อน — wizard 4 ขั้น
  คือเฟส 2
- **แท็บสถานะ** ชี้ไป `/status` เดิม (หน้าตาเก่า) จนกว่าเฟส 3

## การทดสอบ

- logic ล้วนใหม่ (เช่น map ค่า PM2.5 → ระดับ/สี/ป้ายไทย ถ้าไม่มีของเดิมให้ reuse)
  อยู่ `lib/citizen/` + เทสต์ vitest ตามธรรมเนียม repo (`lib/**/__tests__/`)
- UI ตรวจด้วยตาเทียบแคนวาสบน `npm run dev` — ทั้งวิวมือถือและจอคอม (app shell
  กึ่งกลาง) · `npm run lint` + `npm test` ผ่านก่อนจบ
