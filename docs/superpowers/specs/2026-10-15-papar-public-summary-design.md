# หน้าสรุปคุณภาพน้ำประปา (ประชาชน) — Design

วันที่: 2026-10-15 · โมดูล: `smart-papar`

## ที่มา

การ์ด "น้ำประปา" บนหน้าแรกโชว์แค่ค่า NTU ล่าสุด เจ้าของต้องการให้กดแล้วเจอหน้าสรุปคุณภาพน้ำที่ประชาชนอ่านเข้าใจ
พร้อมสรุปงานโบตะกอน และทางเข้าหน้าโบตะกอนของเจ้าหน้าที่ไว้ท้ายหน้า

## Route

- หน้าใหม่ **`/papar`** (`pages/papar/index.jsx`) ไม่ต้องล็อกอิน ใช้ `CitizenShell` (เพิ่ม `/papar` แบบ exact ใน `components/Layout.js`
  — `/papar/flushing` ยังใช้ layout เดิม)
- การ์ดน้ำประปาหน้าแรก (`EnvCards`) → `/papar` (เดิมไป `/papar/flushing`)
- ปุ่มท้ายหน้า "โบตะกอน" → `/papar/flushing` (หน้าเจ้าหน้าที่เดิม)

## เนื้อหา (บนลงล่าง)

1. **การ์ดสรุป NTU** — ค่าน้ำประปาจ่ายออกล่าสุด + ป้ายระดับ (`waterLevel` เดิม) + "ข้อมูลวันที่ …" + หมายเหตุ
   "*ค่ามาตรฐานของกรมอนามัยไม่เกิน 5 NTU สามารถใช้อุปโภคบริโภคได้ (ณ หน้าโรงกรองประปาเทศบาลเมืองตาคลี)"
2. **การ์ด pH + การ์ด TDS** — ค่าล่าสุด, เกณฑ์, คำอธิบายสั้น, ป้ายสรุป **"อยู่ในเกณฑ์มาตรฐาน" / "เกินเกณฑ์"**
   (pH 6.5–8.5 · TDS ≤ 600 mg/L — เจ้าของยืนยัน 2026-10-15)
3. **ตารางรายวัน 30 วันล่าสุดที่มีข้อมูล** — วันที่ · NTU · pH · TDS · สถานะ (ทุกค่าที่มีอยู่ในเกณฑ์ = ปกติ)
4. **การ์ดงานโบตะกอน** — % ใสแล้วของวันล่าสุดที่มีงาน (ตัวใหญ่ + วันที่) + ตารางย่อ 3 วันล่าสุด (วันที่ · จุดที่โบ · % ใสแล้ว)
5. **ปุ่ม "โบตะกอน"**

## ข้อมูล

- แสดง**เฉพาะค่าน้ำประปาจ่ายออก (`tap`)** — ไม่แสดงน้ำดิบ (ขุ่นเป็นปกติ อาจทำให้ประชาชนเข้าใจผิด)
- API สาธารณะ `GET /api/smart-papar/water-quality/public-summary` — ตัวเลขรวมเท่านั้น ไม่มีชื่อเจ้าหน้าที่/ตำแหน่ง/รูป
  · cache สั้น · API `public-latest` เดิมไม่แตะ
- logic ล้วน + เทสต์: `lib/smart-papar/publicSummary.js` — เกณฑ์ (`WATER_STANDARDS`), ตัดสินรายค่า/รายวัน, รวมงานโบรายวัน (วันไทย)

## ไม่ทำ

ตารางรายเดือน/รายปี (เจ้าของเลือกแค่ 30 วัน), ค่าน้ำดิบ, คลอรีน (มีข้อมูลแค่ 1 วัน)
